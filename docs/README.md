# Testmex docs

Documentation site built with [Docusaurus](https://docusaurus.io/).

## Development

From the monorepo root:

```bash
pnpm docs:start
# or
pnpm nx start docs
```

From this directory:

```bash
pnpm start
```

## Production build

```bash
pnpm docs:build
# or
pnpm nx build docs
```

Serve the production build locally:

```bash
pnpm nx serve docs
```
