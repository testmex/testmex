# Introduction

**Testmex** helps you migrate test suites from Jest to [Vitest](https://vitest.dev/).

The **vitestify** CLI scans your workspace, applies codemods, and updates configuration so you can move off Jest with confidence.

## Quick start

Build the CLI from the monorepo root:

```bash
pnpm nx build vitestify
```

Run it against your project:

```bash
pnpm nx build vitestify && node packages/vitestify/dist/cli.js
```
