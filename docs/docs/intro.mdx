# Introduction

**TestMex** is the home of opinionated, spicy JavaScript testing tools — making testing easier and more meaningful for humans and agents.

**vitestify** is the first tool: a CLI that scans your workspace, applies codemods, and updates configuration so you can migrate test suites from Jest to [Vitest](https://vitest.dev/) with confidence.

## Quick start

Build the CLI from the monorepo root:

```bash
pnpm nx build vitestify
```

Run it against your project:

```bash
pnpm nx build vitestify && node packages/vitestify/dist/cli.js
```
