# Future work

Vitestify ships the migration core first. These are the natural next steps:

- Broader framework support beyond Angular (for example React and Vue)
- Richer transform coverage for less common Jest APIs and project layouts
- Better guidance and agent instructions for exotic setups that stay manual
- Deeper integration with monorepo tooling and CI-friendly dry runs

Vitestify will stay a migration tool — not a runtime Jest compatibility layer or a general-purpose test helper library.
