# Getting started

Agents can migrate Jest to Vitest, but tests are your harness's core feedback loop. Changes need careful review. Vitestify handles common cases deterministically, so you review exceptions, not mechanical noise.

Just run the following command from your workspace root:

```sh
npx @testmex/vitestify
```

Vitestify will scan for Jest configs, setup files, and tests, apply transforms. For what’s covered today, see [Scope](./scope).
